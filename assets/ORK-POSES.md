# 오크 보이와 그레친 조형 검증

공개 전장에는 보이 20명과 그레친 10명의 개별 입체 조형이 들어 있다. 각 조형은 제품 사진 없이 렌더링된다. 보이 1·20과 그레친 5는 공식 회전 촬영본과도 연결된다. 나머지 27개는 앞쪽 한 방향에서 보이는 무기·관절·복장만 직접 대조했다. [스타터 세트](https://www.warhammer.com/ko-KR/shop/40k-starter-set-2026-eng) · [공식 오크 단체 촬영판](https://www.warhammer.com/app/resources/catalog/product/920x950/60010199082_WH40KStarterSet03.jpg)

## 대조 방법

1. 배치도에 매긴 기물 번호를 단체 촬영판에서 분리한 각 기물에 대응시켰다. 30개 모두 다른 사진에 대응한다. 배치 사진에서 가려진 **보이 2·6·14·19**의 번호 대응은 추정이다. 해당 네 사진에서도 손과 무기는 직접 확인할 수 있다. [번호 대응표](../data/portrait-map.json)
2. 각 실루엣을 195 × 197픽셀 연구 화면에 맞추고 베이스 폭, 머리·허리 중심, 오른쪽과 왼쪽의 어깨·팔꿈치·손·무릎·발, 소품의 보이는 끝을 기록했다. 놉은 40mm, 일반 보이는 32mm, 그레친은 25mm 베이스를 사용했다. 발 위치 차이로 앞뒤 디딤을 근사했다. [좌표와 장비 기록](ork-poses.mjs)
3. 두 보이 분대의 1번 모델을 각각 콤비 로킷 놉과 커스텀 슈타 놉으로 대조했다. 나머지 보이와 그레친의 외형용 소품은 판정 프로필을 바꾸지 않는다. 아래 표의 오른손과 왼손은 모델 자신의 손이다. [편성 프로필](../rules/profiles.mjs) · [자료 출처](../rules/SOURCES.md)

## 보이 20명

보이 20번은 아래 초기 조형을 만든 뒤 회전 사진으로 칼을 든 팔의 깊이와 어깨 위 총 방향을 다시 맞췄다. 초기 수치와 새 조형의 같은 시점 비교는 별도로 기록했다. [보이 20번 최신 실물 비교](BOY-TWENTY-COMPARISON.md)

| 게임 말 | 양손과 자세 | 첫 번째와 두 번째 모델을 구분하는 표식 |

|---|---|---|
| 1 / 8 | 몸을 앞으로 굽히고 긴 총을 허리에서 양손으로 잡음 | 1은 붉은 머리술과 장화, 8은 끝이 검은 머리술과 맨발 |
| 2 / 9 | 양팔을 얼굴 앞에 모아 짧고 굵은 총구를 겨눔 | 2는 드러난 머리에 총구가 카메라 쪽을 향하고, 9는 검은 뾰족 투구와 옆으로 향한 총구 |
| 3 / 6 | 몸을 웅크리고 굵은 총열을 허리에서 받침 | 3은 검은 투구와 맨발, 6은 구리색 투구·장화·붉은 손목 부분 |

| 5 / 7 | 왼손 칼을 머리 위로 올리고 오른손에 총을 듦 | 5는 장화·낮은 돌·세운 긴 총, 7은 맨발과 아래로 기울인 짧은 총 |

## 초기 조형의 렌더링 결과

| 검증 | 결과 |
|---|---|
| 정면 외곽 겹침 | 이전 조형(커밋 `be252b9`) 평균 51.22%, 이번 조형 68.90%. 30개 모두 개선됐고 개별 결과는 58.9%부터 80.9%까지였다. |
| 공식 회전 촬영 3개와 측후면 비교 | 보이 1의 옆면·뒷면 겹침은 43%·42%, 보이 20은 37%·46%, 그레친 5는 38%·56%. 이 값은 앞면을 보고 만들었을 때 가려진 형태가 얼마나 달라질 수 있는지 보여준다. |
| 렌더링 비용 | 30개 합계 181,268 → 140,964삼각형(22.2% 감소). 게임 말마다 캐시된 메시 한 개를 그리며 재질을 공유한다. 실제 프레임 속도는 측정하지 않았다. |
| 공개 모드 상호작용 | 모델별 정점·법선 유한성, 기하와 모델 번호의 고유성, 세 방향 베이스 선택, 분대·놉 무장 대응 검사 통과. [회귀 검사](../tests/ork-poses.test.mjs) |

정면 수치는 두 버전 모두 같은 스케일과 10° 시점에서 렌더링해 얻었다. 사진과 렌더의 가장 어두운 RGB 채널이 215 미만인 영역을 전경으로 삼고, 평균 발 좌표보다 6픽셀 위에서 잘라 베이스를 제외했다. 겹침은 전경 교집합 면적을 합집합 면적으로 나눈 값이다. 앞면은 조형에 사용한 사진과의 일치도다.

측후면은 실제 회전 촬영이 있는 세 모델에만 측정했다. 8° 높이에서 30° 간격으로 조형을 회전시키고, 낮은 시점의 공식 12장과 비교했다. 각 실루엣을 종횡비를 보존해 같은 크기의 화면에 넣고 아래 15%를 제외했다. 정면과 다음 한 각도로 촬영 순서와 기준 방향을 맞춘 뒤 90°와 180°를 평가했다. 단일 사진만 확인한 27개는 등 장비, 숨은 손가락, 팔과 무기의 앞뒤 간격을 추정했다.

## 그레친 5번의 다각도 보정

칼을 든 왼팔을 머리 위로 뻗고 오른쪽 팔꿈치를 옆으로 벌려, 긴 총의 총구와 탄창, 턱이 앞뒤로 다른 위치에 놓이도록 조형했다. 검은 조끼에는 벌어진 앞섶과 뒤로 들린 옷자락을 만들었다. 한쪽 장화는 기울어진 돌을 딛고 다른 장화는 지면에 닿는다. 이 공개 조형은 직접 만든 입체 도형과 정점색으로 그린다. [공식 제품 갤러리](https://www.warhammer.com/ko-KR/shop/40k-starter-set-2026-eng)

25mm 베이스의 위치·척도를 고정하고 세 높이의 카메라로 수정 전후 메시를 투영했다. 560픽셀 사진에서 베이스와 테두리 2픽셀을 제외한 실루엣의 교집합을 합집합으로 나눴다. 36개 시점 평균은 **39.16% → 78.00%**였다. 조형에 사용하지 않은 여섯 시점은 **35.93% → 78.20%**였다. 36개 시점이 모두 개선됐다. 이전 표의 측후면 측정에서는 정규화한 작은 이미지의 아래 15%를 잘랐다.

| 비교 위치 | 기존 | 수정 |
|---|---:|---:|
| 낮은 시점의 앞면 | 53.37% | 81.41% |
| 양쪽 옆면 | 41.82% / 42.53% | 82.87% / 84.09% |
| 뒷면 | 50.75% | 79.29% |
| 앞쪽으로 벌어진 조끼 끝의 작은 비교 구역 | 7.18% | 50.00% |

기물은 4,264삼각형에서 8,108삼각형이 됐고 베이스 밑부터 칼날 꼭대기까지의 게임 높이는 1.193인치에서 1.313인치가 됐다. 조끼의 작은 주름, 입안과 손가락 사이의 깊이는 사진으로 추정했다. 사진판은 기존의 다각도 복원 모델을 사용한다. 다른 그레친 아홉 기의 위치·법선·색·삼각형 데이터는 이전과 동일했다.
