# 훈련 4의 차량 사격

73쪽에서 추가된 무장은 랜드 스피더와 워트랙의 고정 스타터 편성에 맞췄다. 사거리, 명중, 방어, 상처·피해는 64~66쪽 사격 교육과 54~55쪽 공격 판정을 따른다. 개별 모델의 사격 프로필은 같은 세트용 Assault Force와 ’Ardmob 데이터시트의 앱 채록을 사용했다. 7월판 핸드북 촬영에서 차량의 무기 표 전체를 읽어 낼 수 없어서 인쇄 수치와의 완전한 일치는 미확인이다. [73쪽 실물 편성](https://www.youtube.com/watch?v=TKObcaZUZbw&t=933s) · [64~66쪽 사격 절차](TRAINING-THREE-SHOOTING.md) · [프로필 판본과 출처](SOURCES.md)

| 무기 | 훈련 4에서 처리하는 판정 |
|---|---|
| 워트랙 로킷 런처 | 공격자 D6의 1~2, 3~4, 5~6을 각각 1, 2, 3으로 환산하고 3을 더해 4~6회 공격한다. 피해는 명중과 상처를 거쳐 방어에 실패한 공격당 3이다. |
| 워트랙 커스텀 슈타 | 기본 4회. 18인치 사거리의 절반 이내에 표적 분대가 있으면 속사 2로 6회 공격한다. |
| 랜드 스피더 헤비 플레이머 | 공격 횟수는 D6. 토렌트로 자동 명중해 사격 측이 상처를 바로 굴린다. 사거리와 시야는 표적을 정할 때 확인한다. |
| 랜드 스피더 멀티 멜타 | 2회 공격. 방어에 실패하면 수비자가 피해를 받을 모델을 선택하고 공격자가 해당 공격의 피해량 D6을 굴린다. 18인치의 절반 이내라면 피해에 2를 더한다. 한 공격의 초과 피해는 버린다. |
| 랜드 스피더 스톰퓨리 미사일 | 패트롤 무장표에 따라 1회 공격, 피해 4를 사용한다. |

속사와 멜타의 절반 사거리는 사수의 베이스에서 표적 분대까지 표적 확정 시점에 잰다. 이후 가장 가까웠던 모델이 제거되어도 이미 확정한 무기의 보너스를 유지한다. 무기 속성의 근거는 코어 24.25, 24.30, 24.37이다. 훈련 4의 보병 무기에도 해당하는 속사와 블라스트를 적용한다. 워트랙의 키워드는 Mounted이므로 대차량 무기의 보너스가 붙지 않는다. [11판 코어 규칙 24절](https://assets.warhammer-community.com/eng_01-06_warhammer40k_new40k_core_rules-was6fbu1ix-hfewhmxyiy.pdf)

핸드북에 나온 전력 이동·후퇴 후 사격 제한과 Close-quarters 교전 예외를 유지한다. 별도 패트롤전의 차량 교전 사격, 분대별 사격 후 능력, 전술 및 위험 무기 판정은 이 단계의 교육 범위에서 제외했다. 훈련 3의 기록은 기존 무기 속성과 단계로 재생한다.

무작위 공격 횟수와 피해량은 각각 독립된 플레이어 행동이다. 저장 기록에는 실제 굴린 D6 눈이 남는다. 결과 기록은 식, 추가 보너스, 총값을 분리해 저장한다. 엄격 재생은 판정 전 대기 단계, 피해 대상으로 선택된 모델, 주사위와 총값, 남은 상처를 다시 계산해 검사한다.
